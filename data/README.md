# Data catalog

Data moves one way through four folders. Scripts in `src/` read from one stage and write to the next; nothing is edited by hand.

| Folder | What goes here | Rules |
|---|---|---|
| `raw/` | Files exactly as received | Never modified. If a file needs fixing, a script fixes it and writes to `interim/`. |
| `interim/` | Intermediate steps, e.g. one-hot encoded Q1 roles, group assignments, value-theme mapping | Regenerated by scripts; safe to delete. |
| `processed/` | Analysis-ready tables the statistical tests read | Regenerated by scripts. |
| `final/` | Aggregate outputs reported in the paper: group counts, test results, effect sizes | No respondent-level rows. |

## Source

Chapel Hill-Carrboro City Schools, *Community Priorities Assessment* results workbook, `CHCCS Community Priorities Asessment (SHARED).xlsx` (eight language tabs), published on the CHCCS Together document library: https://www.chccstogether.org/document-library

The results are public, so all stages are committed.

## Datasets

| File | Stage | Contents | Source / produced by |
|---|---|---|---|
| `raw/CHCCS_Respondent_Relationships.xls` | raw* | Q1 (respondent relationship) for all 1,463 responses, one-hot encoded, with source sheet/row, translations and coding notes | Coded from the CHCCS workbook outside this repo |
| `final/respondent_role_counts.csv` | final | Respondents per Q1 role, and how many selected only that role | `src/explore_respondent_groups.py` |
| `final/candidate_group_sizes.csv` | final | Candidate comparison groups with minimum detectable effects | `src/explore_respondent_groups.py` |

\* Strictly this is an interim file: it's already coded from the original workbook. Once the original workbook is in `raw/`, the coding should be reproduced by a script (or the coding steps documented) so the pipeline is reproducible from the CHCCS file.
