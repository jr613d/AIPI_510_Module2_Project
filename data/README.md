# Data catalog

Data moves one way through four folders. Scripts in `src/` read from one stage and write to the next; nothing is edited by hand.

| Folder | What goes here | Rules |
|---|---|---|
| `raw/` | Source files | Never edited by hand. The CHCCS workbook is committed with its free-text fields redacted (see below); the original stays in `raw/private/`, which Git ignores. |
| `interim/` | Intermediate steps | Unused in this project: each script writes analysis-ready tables straight to `processed/`. |
| `processed/` | Analysis-ready tables the statistical tests read | Regenerated by scripts. |
| `final/` | Aggregate outputs reported in the paper: group counts, test results, effect sizes | No respondent-level rows. |

## Source

Chapel Hill-Carrboro City Schools, *Community Priorities Assessment* results workbook, `CHCCS Community Priorities Asessment (SHARED).xlsx` (eight language tabs), published on the CHCCS Together document library: https://www.chccstogether.org/document-library

The workbook is public, but some free-text answers contain personal details (a home address, an email address, children's health information tied to a named school). Republishing them adds nothing to the analysis, so the committed copy has the three open-ended free-text fields blanked on every response row:

| Column | Question |
|---|---|
| P | Q4 Other challenges |
| AD | Q6 Other values |
| AH | Q10 Additional thoughts |

Everything else, including headers, ratings, top-three picks, Q1 write-ins and Q9, is unchanged, and the main analysis gives byte-identical outputs with either copy. To recreate the redacted copy, download the original (SHA-256 `1afc8b9974cae04b0eeb968679f9e3cc4db2dd5a2241320b0340af36d3ae6ea3`) to `raw/private/CHCCS Community Priorities Asessment (SHARED) - original.xlsx` and run `python src/redact_raw_workbook.py`. The exploratory write-in analysis (`exploratory_analysis/04_write_ins`) needs that original and skips itself without it.

## Datasets

| File | Stage | Contents | Produced by |
|---|---|---|---|
| `raw/CHCCS Community Priorities Asessment (SHARED).xlsx` | raw | CHCCS results workbook, eight language tabs, all questions; free-text fields Q4, Q6 and Q10 blanked | `src/redact_raw_workbook.py`, from the original in the CHCCS document library |
| `processed/chccs_respondent_relationships.csv` | processed | Q1 (respondent relationship) for all 1,463 responses, one-hot encoded, with source sheet/row, translations and coding notes | `src/one_hot_encode_q1.py` |
| `processed/q9_value_themes.csv` | processed | Q9 answer per response (original and English), mapped value and theme, parent/non-parent group, and whether it enters the chi-square test | `src/prepare_q9.py` |
| `final/q9_contingency_table.csv` | final | Observed and expected counts, group × theme | `src/run_chi_square.py` |
| `final/q9_test_results.csv` | final | Test used, chi-square, p-values, Cramér's V with bootstrap CI, minimum detectable V, Student Learning difference with Newcombe CI, seed | `src/run_chi_square.py` |
| `final/q9_residuals.csv` | final | Adjusted standardized residuals (post hoc) | `src/run_chi_square.py` |
| `final/q9_theme_percentages.csv` | final | Percent choosing each theme by group, with 95% Wilson CIs | `src/run_chi_square.py` |
| `final/respondent_role_counts.csv` | final | Respondents per Q1 role, and how many selected only that role | `src/explore_respondent_groups.py` |
| `final/candidate_group_sizes.csv` | final | Candidate comparison groups with minimum detectable effects | `src/explore_respondent_groups.py` |

To rebuild from the raw workbook, run from the repo root:

```bash
python src/one_hot_encode_q1.py
python src/explore_respondent_groups.py
python src/prepare_q9.py
python src/run_chi_square.py
python src/make_result_figures.py
```
